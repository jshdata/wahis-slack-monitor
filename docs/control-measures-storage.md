# 방역 조치 파일 저장·조회

`python -m wahis.upload_control_snapshots`는 `data/control_measures_global/manifest.json`에
정의된 6개 CSV의 헤더·크기·건수를 검증한 뒤, 기존 비공개 Railway 버킷에 gzip으로 저장합니다.
업로드 파일을 다시 내려받아 SHA-256과 압축 해제한 원본 바이트까지 검증합니다.
모든 파일 검증 후에만 `wahis/control-measures/manifest.json`을 갱신합니다.
기존 PDF 객체나 Aiven DB는 변경하지 않습니다.

Slack의 **통계·자료 조회 → 방역 조치 조회**에서 질병·연도·반기·영문 국가 부분 검색과
전체 조치 / 접종 시행·금지 / 공식 예방접종 필터를 사용할 수 있습니다.
HPAI는 가금·가금 외 원본 질병 이름을 유지합니다. 건수는 보고된 조치 행 수이며,
실제 시행 횟수·접종 마릿수·접종률을 뜻하지 않습니다.

조회 결과의 **HTML 표 보기**는 같은 조건으로 브라우저용 표 링크를 만듭니다.
링크는 1시간 동안 유효하며 서버 재시작 시 만료될 수 있습니다.
HTML 표는 100건씩 페이지 이동으로 전체 결과를 조회하며,
서버에 전체 결과 HTML을 메모리로 쌓지 않습니다. DB 적재는 하지 않습니다.

조회는 질병별 파일을 필요할 때 다운로드해 임시 디스크의 SQLite 검색 캐시로 만듭니다.
CSV는 1,000행씩 처리하므로 전체 데이터를 메모리에 올리지 않습니다.
캐시는 인스턴스 재시작·재배포 시 재생성 가능하며 영구 Volume은 필요하지 않습니다.
파일 SHA-256과 행 수가 일치하지 않으면 캐시를 공개하지 않습니다.
같은 스냅샷의 반복 조회는 로컬 캐시를 사용합니다. manifest는 60초 캐시합니다.

현재 스냅샷은 2005년~2026년 상반기의 기존 수집 자료입니다.
이 작업은 자동 원천 수집을 새로 추가하지 않습니다. 최신 CSV를 수집한 경우
manifest와 함께 업로드 명령을 다시 실행해야 새 자료가 반영됩니다.
접속 설정은 PDF와 같은 `WOAH_PDF_STORAGE=railway`, `S3_*` 환경변수를 사용합니다.
업로드 결과는 로컬 `data/control_measures_global/bucket_upload_result.json`에 기록됩니다.
