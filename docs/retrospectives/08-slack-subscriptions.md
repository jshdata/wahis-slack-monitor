# RET-SLACK-01 — 관심 조건에 따른 Slack 채널 발송

- **일자** 2026-11-23 (KST)
- **상태** 확인 필요
- **근거** 코드 확인과 로컬 모의 테스트

기존 웹훅은 한 채널에 연결되고, 전송 상태는 보고서 단위였다. 같은 보고를 여러 채널에 보내면 일부 채널 실패에 따른 재시도에서 이미 받은 채널이 같은 보고를 다시 받을 수 있다.

첫 버전은 채널별 Incoming Webhook과 운영자 설정을 사용한다. 국가·질병·축종 조건을 모두 충족하는 채널에 기존 메시지를 추가 발송한다. 축종 비교에는 Slack 화면에서 생략되기 전의 전체 이름을 사용한다. 보고별 MySQL 잠금과 채널별 성공 기록을 추가해 기존 보고서 재시도에서 이미 발송 완료한 채널을 건너뛴다.

구독 조건 및 부분 실패 후 재시도 2개, 보고서 상세 7개, ntfy 3개 테스트가 통과했다. 오류 알림 테스트 8개 중 1개는 모의 처리되지 않은 ntfy 초기화에서 외부 DB 연결이 차단되어 중단됐다.

실제 MySQL 테이블 생성과 Slack 전송은 확인 대기 중이다. Slack 수신 후 DB에 성공을 기록하기 전에 중단되면 중복 가능성이 있다. 재시도는 현재 구독 설정과 그 시점에 조회되는 보고서 상세를 사용한다.

관련 파일은 [구독 처리](../../slack/subscriptions.py), [회귀 테스트](../../tests/test_slack_subscriptions.py), [설정 방법](../../README.md#slack-채널별-관심-조건-구독)이다.
