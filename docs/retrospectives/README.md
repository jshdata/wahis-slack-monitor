## 현재 선택한 원칙

1. 신규 **보고서**는 `report_id`, 발생 통계는 고유 `outbreak_id`로 판단합니다.
2. 신규 발생 알림은 해당 보고서가 처음 등록한 ID만 셉니다. 기존 ID 수정은 제외합니다.
3. 발생지 사육/야생은 발생지 API의 `isWild`로 판단합니다. 종 이름이나 보고서 합계로 추정하지 않습니다.
4. 전체 JSON을 저장하는 대신 축종·분류·완료 버전만 추가 저장합니다.
   기존 보고서 단위 정량 데이터와 발생일 등은 유지합니다.
5. 공식 Reason, 자체 분석상 공백, 감염 동물 수, 발생지 수를 서로 바꿔 부르지 않습니다.
6. 재시도 가능한 실패를 완료로 표시하지 않으며, 미확인을 0이나 사육으로 간주하지 않습니다.
