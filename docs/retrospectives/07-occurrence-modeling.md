# RET-MODEL-01 — 발생 여부 로지스틱 회귀의 첫 탐색 평가

- **일자:** 2026-11-12 (KST)
- **상태:** 진행 중
- **근거:** 로컬 CSV 확인, 실행 결과, 특성 시점·중복 처리 테스트

**배경·영향:** 수집·조회 프로젝트에 발생 여부 모델링을 추가하고자 했다. 사용자가 사육·야생 자료의 미완료를 알려 해당 구분을 제외했다.

**관찰과 원인:** CSV에 HPAI 47,231건, 132개국이 있다. 사육·비가금 범주를 합쳤다.
전체 수집 범위와 과거 공개 시점은 확인되지 않았고 비가금 범주의 원천 명칭은 2017년 이후를 나타낸다.

**시도와 선택 이유:** 외부 변수를 붙이기 전 과거 발생과 계절성·국가로 기준 모델을 구현했다.
무작위 분할 대신 시간 분할, 학습에서만 전처리 적합, 검증에서만 임계값 선택을 적용했다.

**조치와 검증:** 2026-06을 종료 월로 실행. 학습 89개국, 평가 4,361 국가·월.
로지스틱 ROC-AUC 0.864, AP 0.783, F1 0.683. 전월 발생 기준 F1 0.766보다 낮다.
단순 기준보다 우수하다는 결론이나 배포는 하지 않았다.
`python -m unittest modeling.test_hpai_logistic` 3개 통과. 목표·미래 월 변화가 이전 특성에 영향을 주지 않는지,
범주 통합·중복 제거와 충돌 ID 거부를 확인했다. 실제 공개 시점 누출은 이 테스트로 검증되지 않는다.

**남은 한계·다음 확인:** 미기록을 0으로 임시 간주한 탐색 분석이다. 지연 보고·수정에 의한 가용 시점 누출,
국가 선택 편향·장기 범주 변화가 남는다. 수집 완전성·공개 이력 확인 후 순차 평가가 필요하다.

**관련 근거:** [모델 설명과 실행 결과](../../modeling/README.md), [구현](../../modeling/hpai_logistic.py), [테스트](../../modeling/test_hpai_logistic.py).

**후속 기록:** 2026-11-12 — [순차 평가](../../modeling/rolling_logistic.py) 추가.
2017년 이후 자료와 평가 이전 이력으로 고정한 39개국, 2021~2026-06을 평가했다.
매년 과거 검증 구간에서만 C·임계값을 선택하고 재학습했다. log1p 건수와 과거 발생 여부 특성을 추가했다.
동일 표본의 전월 기준 대비 F1 0.790 대 0.786, 재현율 0.821 대 0.789,
정밀도 0.762 대 0.783. 2022·2024년 F1은 기준보다 낮아 지속적 우위로 주장하지 않는다.
이전 평가와 표본이 달라 직접적인 성능 상승으로 해석하지 않는다.
스냅샷 재분석의 수집 누락·지연 보고 한계는 남으며 외부 발송·운영 배포는 하지 않았다.
검증: 순차 평가 전체 실행 완료. 특성의 목표값 비의존성 검사를 추가해 단위 테스트 4개 통과,
`git diff --check` 통과. 다른 작업의 기존 변경은 보존했다.
