# HPAI 국가·월별 발생 여부 로지스틱 회귀

2026-11-12 KST 실행. 사육·야생 구분 없이 두 HPAI 원천 질병 범주를 합친다.
목표는 다음 달 고유 발생지 기록이 1건 이상 존재하는지다. 실제 감염 여부나 인과관계의 추정이 아니다.

## 실행

프로젝트 루트에서 실행한다. 운영 의존성과 분리했다.

```powershell
python -m pip install -r modeling/requirements.txt
python modeling/hpai_logistic.py --end-month 2026-06
python -m unittest modeling.test_hpai_logistic
```

원천은 로컬 `wahis_outbreaks_all.csv`. DB 변경이나 외부 알림은 없다.
결과는 `data/modeling/hpai_logistic/`의 metrics.json, test_predictions.csv,
coefficients.csv, monthly_panel.csv에 저장된다. CSV는 기존 gitignore 적용 대상이다.
계수는 표준화된 수치 특성의 단위 또는 국가 더미에 대한 정규화 회귀계수이며 인과효과·유의성 검정이 아니다.

## 설계

- 고유 outbreak_id 중복 제거. 서로 다른 국가·월을 가진 동일 ID는 중단한다.
- 설명변수: 전월·전년 동월 발생 수, 과거 3·6개월 합계, 월의 sin/cos, 국가.
- 모든 발생 이력은 목표 월보다 이전 월만 사용한다. 스케일링·국가 인코딩은 학습 자료에만 적합한다.
- 학습 2006-02~2018-04, 검증 2018-05~2022-05, 평가 2022-06~2026-06.
- 학습에서 관측된 89개국으로 고정한다. 이후에만 관측된 43개국은 제외된다.
- C=1 정규화 로지스틱 회귀. 검증 F1로 임계값 0.17을 선택하고 평가에는 고정한다.
- 최신 월은 보수적으로 제외해 2026-06까지 사용했으나 이 날짜가 완전성을 보증하지는 않는다.

## 첫 실행 결과

평가 4,361 국가·월, 양성 1,224건(28.1%). Average precision은 PR 곡선의 요약 지표다.

| 지표 | 로지스틱 회귀 | 전월 발생 여부 기준 | 학습 양성률 고정 |
|---|---:|---:|---:|
| ROC-AUC | 0.864 | 0.838 | 0.500 |
| Average precision | 0.783 | 0.652 | 0.281 |
| 정밀도 | 0.756 | 0.763 | 0.000 |
| 재현율 | 0.623 | 0.769 | 0.000 |
| F1 | 0.683 | 0.766 | 0.000 |
| Brier score (낮을수록 좋음) | 0.134 | 0.132 | 0.241 |

로지스틱 회귀의 TP=762, FP=246, FN=462, TN=2,891.
순위 지표는 전월 기준보다 높지만 선택된 임계값의 F1과 Brier는 낮다.
따라서 단순 기준을 이긴 예측 모델로 결론 내리지 않는다. 평가 결과를 보고 임계값을 다시 고르지 않았다.

## 해석의 한계와 다음 작업

**탐색용 스냅샷 분석이며 운영용 예측 검증이 아니다.**
자료가 없는 국가·월은 임시로 0으로 간주했다. 수집 완전성이나 공식 무발생 여부는 확인되지 않았다.
과거 시점별 제출·공개 이력이 없으므로, 당시 알려지지 않았던 발생을 과거 특성에 넣는 정보 누출이 가능하다.
단순 shift 테스트는 이 보고 지연 문제를 해결하지 못한다.
비가금 범주에 2017년 이후라는 원천 정의가 있어 장기 비교의 일관성도 미확인이다.
처음부터 자료가 없는 국가와 처음 관측되기 전의 기간에 대한 선택·관측 편향이 남는다.
축종·사육/야생 변수, 기후·사육 규모 등 외부 변수는 사용하지 않았다.

다음 우선순위는 국가·월별 수집/신고 범위 확인, 과거 공개 시점 복원 가능성 확인,
2017년 이후 비교 가능한 기간의 별도 사전 설계, 순차 재학습 평가, 확률 보정과 외부 변수의 추가 가치 검증이다.
운영 알림이나 최신 국가별 위험 확률은 이번 분석에서 제공하지 않는다.

## 후속 개선: 2017년 이후 순차 재학습

실행: `python -m modeling.rolling_logistic`

2017-01 이후 원천만 사용하고 12개월 특성을 만든다. 2018~2019년에 발생 기록이 있는
39개국을 고정해 2021~2026-06의 2,574 국가·월을 평가한다. 이는 전체 국가에 대한 평가가 아니다.
매년 직전 1년을 검증 구간으로 두고 이전 자료로 학습해 C(0.1/1/10)와 F1 임계값을 선택한다.
선택 후 직전 연도까지 재학습하고 이후 1년(2026년은 6개월)을 평가한다.
발생 건수 log1p 변환과 전월·전년 동월 발생 여부를 추가해 큰 건수의 영향을 줄였다.
사육·야생 구분이나 해당 범주의 비중·건수는 설명변수에 사용하지 않는다.

| 지표 | 개선 로지스틱 | 같은 표본의 전월 기준 |
|---|---:|---:|
| ROC-AUC | 0.917 | 0.826 |
| Average precision | 0.887 | 0.699 |
| 정밀도 | 0.762 | 0.783 |
| 재현율 | 0.821 | 0.789 |
| F1 | 0.790 | 0.786 |
| Brier | 0.112 | 0.166 |

| 평가 연도 | 로지스틱 F1 | 전월 기준 F1 |
|---|---:|---:|
| 2021 | 0.774 | 0.762 |
| 2022 | 0.848 | 0.871 |
| 2023 | 0.813 | 0.803 |
| 2024 | 0.697 | 0.717 |
| 2025 | 0.774 | 0.747 |
| 2026 상반기 | 0.796 | 0.784 |

전체 F1 차이는 약 0.004로 작고 2022·2024년에는 기준보다 낮다. 통계적 우위를 입증하지 않았다.
확률 순위·Brier가 개선됐지만 0/1 예측인 전월 기준과 비교한 것으로 확률 보정 완료를 뜻하지 않는다.
이전 실험과 국가·기간이 달라 기존 F1 0.683과 직접 비교할 수 없다.
이미 본 스냅샷의 후속 재분석이며 새 미관측 자료에 대한 확증 검증이 아니다.
2017년 이후 제한은 범주 차이를 줄이기 위한 것이며 수집 완전성·지연 보고 문제를 해결하지 못한다.
결과: `data/modeling/hpai_rolling/metrics.json`, `predictions.csv`.

현재 활용 범위는 후속 조사 대상의 순위를 검토하는 연구용이다. 실제 경보 발송 전에는
국가·월별 관측 범위와 보고 가용 시점을 확보하고 새 기간에서 검증해야 한다.

## 추가 데이터의 우선순위 (2026-11-12)

1. 국가·기간별 수집 완료 상태, 보고서 제출일·최초 수집일·상세 적재 완료 상태를 확인한다.
   최초 수집일과 원천 공개일은 구분한다. 미수집을 무발생으로 처리하지 않는 것이 우선이다.
2. 인접국 최근 1·3개월 발생 건수를 추가해 동일 평가 표본에서 효과를 비교한다.
3. 직전 월 기온·강수량(ERA5)을 추가한다. 예측 대상 월의 실제 기후를 미리 사용하지 않는다.
4. 예측 시점에 공개된 국가별 닭·오리 사육 두수(FAOSTAT)를 추가한다.

위 항목은 후속 계획이며 아직 구현·수집하지 않았다. 사육·야생 구분 변수는 계속 제외한다.
모델 중요도를 인과효과로 해석하지 않는다.

원천 자료 제공처: [Copernicus](https://climate.copernicus.eu/about-data-and-methods),
[FAOSTAT](https://faostat.fao.org/).
원천·개별 예측 CSV는 로컬에 두고, 재현 검토용 집계 지표는 `results/`에 보관한다.
