# Country boundary reference

`country_boundaries.geojson` contains Natural Earth **v5.1.2**, 1:50m Admin-0
Countries. Geometry is unchanged; only ADMIN, NAME, NAME_LONG, FORMAL_EN,
BRK_NAME, ISO_A3 and ISO_A3_EH properties are retained.

Source: https://github.com/nvkelso/natural-earth-vector/blob/v5.1.2/geojson/ne_50m_admin_0_countries.geojson

License: public domain, https://www.naturalearthdata.com/about/terms-of-use/

Bundled on 2026-10-29 so opening a report does not require a separate boundary
download. This is a generalized cartographic reference, not an official legal,
administrative, outbreak, quarantine, or risk boundary. Country labels are
matched exactly (plus explicit aliases); unknown labels remain unshaded.
